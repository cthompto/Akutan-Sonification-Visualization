# Akutan-Sonification-Visualization
Akutan Sonification Collab Code

## Overview
Visualizing the data sonification of Akutan Island seismic data.

### Versions

#### Initial Design
This design connects the sound files to a visual space containing a 3D map of the islands.

#### Draft 2
Adds bloom, color, automatic sound switching, improved model scaling, and movement.

#### Draft 3
Explores color shifting.

#### Draft 4
Added model pan and rotation shift.
